### About

I'm a Lead Software Engineer at **Stackly**, where I lead a 12-member backend team building the **ONE Enterprise Cloud Platform** — HRMS, ERP, CRM and Finance — and own platform administration and access control (RBAC).

- Designing scalable backend services with **Java and Spring Boot**
- Currently building **OpenMesh-Gateway**, a multi-tenant API gateway and traffic control plane
- Long-time competitive programmer, sharpening problem solving every week
- Enjoy crafting interactive 3D and animated interfaces on the frontend
- Based in Hyderabad, India
